# Что показывать работодателям с hh.ru

Один домен портфолио, **разные входы** под тип вакансии. В резюме на hh — одна «главная» ссылка; в сопроводительном письме — уточняете якорь.

## Базовая ссылка в резюме

```
https://spiritwalker84.github.io/freelance-portfolio/
```

Главная — автоматизация и боты; карточки МП — `/marketplace/`.

В блоке «О себе» или «Портфолио» добавьте вторую строку без второго сайта:

| Направление | Куда вести HR |
|-------------|----------------|
| Python, боты, backend, n8n, интеграции | **Главная** + разделы «Кейсы», «Визуал» (лендинги) |
| AI-креатор / дизайнер карточек WB/Ozon | **`/marketplace/`** |
| Универсальный digital (и код, и контент) | Главная + фраза: «карточки МП — ссылка marketplace на том же сайте» |

Пример для поля «Сайт» при отклике на **разработку**:

> https://spiritwalker84.github.io/freelance-portfolio/ — боты, FastAPI; карточки: …/marketplace/

Пример при отклике на **AI-креатор карточек**:

> https://spiritwalker84.github.io/freelance-portfolio/marketplace/ — слайды 3:4, три кейса

## Что смотрит HR на hh (по типу вакансии)

### Вакансии «разработчик / автоматизация / Telegram»

Показывайте на главной:

1. **Кейсы с GitHub** (FGIp*, myfreebot, парсеры) — задача → стек → результат.
2. **Live-демо** лендингов (`#visual`) — форма + backend.
3. **Стек** в marquee и в тексте резюме (Python, FastAPI, Docker, LLM).

Карточки МП **не в заголовке резюме**; при желании одна строка: «дополнительно — визуал для маркетплейсов (отдельный раздел сайта)».

### Вакансии «дизайнер инфографики / AI-креатор WB/Ozon»

Показывайте **`/marketplace/`**:

1. Три кейса со **всеми слайдами** (воронка карточки).
2. Пакеты и сроки (ориентиры).
3. Честный дисклеймер: учебные сэмплы по ТЗ Kwork; в работе — товар заказчика.

В резюме заголовок ближе к вакансии, например: «AI-креатор / дизайн карточек маркетплейсов»; в опыте — FGg02/FGg03 как **проекты обучения + пайплайн** (промпты, сборка 900×1200, Python/Pillow).

Ссылку **`/showcase/mp/`** в hh **не обязательно** — она для Kwork без контактов.

### Вакансии в агентствах e-commerce («и контент, и автоматизация»)

Сильная связка на **главной** + **`/marketplace/`**:

- селлеру нужны и **карточки**, и **бот заявок** — на marketplace в пакете «под ключ» есть отсылка к автоматизации;
- на собеседовании: один человек закрывает визуал и простой контур уведомлений.

## Что приложить кроме ссылки

| Материал | Зачем |
|----------|--------|
| PDF резюме (1–2 стр.) | hh часто смотрит до клика по сайту |
| GitHub | обязателен для dev-вакансий |
| Короткое сопроводительное | «Откликаюсь на …; релевантные работы: …/marketplace/#case-chair» |

## Чего не делать

- Не ставить в заголовок hh «боты и карточки и парсеры» — размывает профиль.
- Не давать Kwork-ссылку `showcase/mp` в резюме для hh — там нет контактов; hr не сможет связаться.
- Не выдавать учебные кейсы за коммерческие без пометки — на сайте дисклеймер уже есть, в интервью повторите.
